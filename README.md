# Mark the Hub — markthehub.com

Web de Mark (hub creativo). Una sola página estática: `index.html` + `img/`.

- Publicada en Netlify (proyecto calm-pegasus-f14d40), dominio markthehub.com.
- Cada cambio en la rama `main` se publica automáticamente.
- Vídeos de los casos: YouTube, incrustados en un reproductor sobre la página.
